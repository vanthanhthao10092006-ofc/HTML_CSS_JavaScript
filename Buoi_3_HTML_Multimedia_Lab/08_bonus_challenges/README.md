# BONUS CHALLENGES

## 1. Picture / art direction
Tìm hiểu `<picture>` và tạo hai crop ảnh khác nhau cho mobile/desktop.

## 2. Multiple video sources
Thêm WebM trước MP4 và giải thích browser chọn source thế nào.

## 3. Iframe capability
Từ `sandbox` rỗng, chỉ cấp `allow-scripts`. So sánh với không sandbox.

## 4. SVG responsive icon
Tạo icon bằng `path`, bỏ width cố định và điều khiển kích thước bằng CSS.

## 5. Accessibility audit
Tìm toàn bộ media trong bài của bạn và trả lời: nếu không nhìn/nghe được media này, người dùng còn lấy được thông tin chính không?
