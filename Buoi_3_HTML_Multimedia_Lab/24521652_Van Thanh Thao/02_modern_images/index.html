02 — Modern Images

Hiệu năng + responsive.

Width + Height

Khai báo kích thước/tỉ lệ gốc giúp browser dành chỗ trước; CSS vẫn làm ảnh responsive.

Lazy loading

<img ... loading="lazy">

Phù hợp với media ở phía dưới trang; không phải cứ có ảnh là gắn lazy.

Responsive image

<img
 src="hero-1200.jpg"
 srcset="hero-480.jpg 480w, hero-1200.jpg 1200w"
 sizes="(max-width: 600px) 100vw, 900px"
 alt="...">

srcset: có những file nào. sizes: ảnh sẽ chiếm bao nhiêu không gian.
