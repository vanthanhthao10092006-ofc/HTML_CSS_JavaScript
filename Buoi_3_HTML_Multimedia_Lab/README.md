# BUỔI 3 — HTML MULTIMEDIA LAB

Bộ lab đi từ cơ bản đến nâng cao, thiết kế cho một tiết giảng khoảng 45 phút và bài thực hành cá nhân sau giờ học.

## Bắt đầu nhanh
1. Giải nén thư mục.
2. **Khuyến nghị Windows:** double-click `RUN_SERVER.bat`, sau đó browser mở `http://localhost:8000/START_HERE.html`.
3. macOS/Linux: chạy `./RUN_SERVER.sh` rồi mở URL được in ra.
4. Có thể mở trực tiếp `START_HERE.html`, nhưng local server ổn định hơn cho WebVTT/iframe.
5. Khi live-code, mở song song VS Code + browser.
6. Không cần internet: ảnh, video, audio, SVG và VTT mẫu đều nằm trong `assets/`.

## Lộ trình
- `00_demo_basic`: img, src, alt, đường dẫn.
- `01_image_semantic`: figure, figcaption, alt có ý nghĩa.
- `02_modern_images`: width/height, lazy loading, srcset, sizes.
- `03_video_audio`: video, audio, source, poster, preload, track/WebVTT.
- `04_iframe_security`: iframe, title, loading, sandbox.
- `05_svg`: raster vs vector, inline SVG, viewBox, accessibility.
- `06_personal_lab`: starter + solution bài cá nhân tổng hợp.
- `07_debug_challenge`: bắt lỗi multimedia HTML.
- `08_bonus_challenges`: bài nâng cao.

## Công thức nhớ
`MEDIA → SOURCE → MEANING → FALLBACK → PERFORMANCE/SECURITY`
