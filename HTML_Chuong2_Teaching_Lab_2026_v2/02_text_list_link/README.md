# Level 02 — Text, List, Link

## Mục tiêu
Biến một đoạn nội dung thô thành HTML có cấu trúc.

## 3 quyết định quan trọng
1. **Heading**: phần này nằm ở cấp nào?
2. **List**: thứ tự có quan trọng không?
3. **Link**: người đọc có biết link sẽ dẫn đi đâu không?

## Mẹo nhớ list
- đổi thứ tự vẫn không sao → `ul`.
- đổi thứ tự làm quy trình sai → `ol`.
