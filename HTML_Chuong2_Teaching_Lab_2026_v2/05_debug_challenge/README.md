# Level 05 — Debug Challenge

## Luật chơi — 8 đến 10 phút
- Không mở `solution.html` trong 6 phút đầu.
- Mỗi nhóm sửa `broken.html`.
- Mỗi lỗi phải ghi thêm **vì sao sai** vào `ANSWER_KEY.md` hoặc giải thích miệng.

## Cách tính điểm
- +1: tìm đúng lỗi.
- +1: sửa đúng.
- +1 bonus: giải thích đúng quy tắc.

## Thông điệp cần nhớ
> **Browser cố sửa lỗi cho bạn. Vì vậy nhìn thấy trang ≠ HTML đúng.**

## Các nhóm lỗi cần tìm
- document metadata;
- mismatched tags;
- bad nesting;
- list structure;
- attribute syntax;
- heading structure;
- semantic placement.
