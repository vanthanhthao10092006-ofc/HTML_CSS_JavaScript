# Exercise Bank — dùng để gọi sinh viên làm nhanh trên lớp

## 1 phút — Element
Viết một `p` có nội dung “HTML describes meaning.”

## 2 phút — Attribute
Tạo link tới MDN với link text “Đọc tài liệu HTML”.

## 2 phút — Nesting
Sửa:

```html
<p>Tôi <strong>rất <em>thích HTML</strong></em>.</p>
```

## 3 phút — List choice
Chọn `ul` hay `ol`:
1. ba nguyên liệu làm bánh;
2. năm bước đăng ký môn;
3. ba tính năng ứng dụng;
4. top 5 sản phẩm theo thứ hạng.

## 3 phút — Heading
Sửa cấu trúc:

```html
<h1>Khóa Web</h1>
<h3>HTML</h3>
<h5>Element</h5>
```

## 5 phút — Link paths
Giả sử:

```text
project/
├─ index.html
├─ pages/
│  └─ about.html
└─ images/
   └─ logo.png
```

Hỏi:
- từ `index.html` link tới `pages/about.html` viết gì?
- từ `pages/about.html` link về `index.html` viết gì?

## 5 phút — Semantic choice
Gắn tag hợp lý cho:
- logo + site name;
- menu chính;
- nội dung trung tâm;
- bài tin;
- sidebar “đọc thêm”;
- copyright cuối trang.

## 8 phút — Metadata
Viết `head` cho sản phẩm “AI Career Coach”.
Phải có: charset, viewport, title, description, og:title, og:description, og:type.

## 10 phút — Mini landing page
Không CSS. Phải có:
- `header/nav`;
- `main`;
- hero `section` có `h1`;
- features `section` có 3 `article`;
- `ol` 3 bước;
- footer + mailto.
