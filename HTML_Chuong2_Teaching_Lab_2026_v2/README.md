## Tư duy cốt lõi: 4 câu hỏi trước khi gõ HTML
1. **Nội dung này là gì?** → tiêu đề, đoạn văn, danh sách, liên kết, khu vực...
2. **Thẻ nào mô tả đúng ý nghĩa nhất?** → `h1`, `p`, `ul`, `a`, `section`...
3. **Có cần thêm thông tin cho thẻ không?** → attribute như `href`, `id`, `lang`, `datetime`...
4. **Cấu trúc có đúng không?** → nesting, heading order, validator.

> Mẹo nhớ: **WHAT → TAG → ATTR → CHECK**.

## Cách chạy
1. Mở thư mục này bằng VS Code.
2. Mở file `.html` bằng browser.
3. Sửa code → Save → Refresh.
4. Khi bài dài hơn, mở bằng VS Code Live Server nếu máy có extension này.
5. Cuối cùng đưa code qua W3C Markup Validator để kiểm tra cấu trúc.
